## Installation Steps (script 04)

```bash
# 1. Activate ROCm env
conda activate rocm-comfyui-r9700

# 2. Clone ComfyUI
git clone https://github.com/comfyanonymous/ComfyUI.git \
  /mnt/c/ai_tools/comfyui-rocm

cd /mnt/c/ai_tools/comfyui-rocm

# 3. Create constraints.txt to prevent ROCm→CUDA downgrade
cat > constraints.txt << 'EOF'
torch==2.5.1+rocm6.2
torchvision==0.20.1+rocm6.2
torchaudio==2.5.1+rocm6.2
EOF

# 4. Install requirements with constraints
pip install -r requirements.txt -c constraints.txt

# 5. Verify GPU
python -c "import torch; print(torch.cuda.get_device_name(0)); print(torch.version.hip)"
```

## Launch Script

Generated by script 04 at `/mnt/c/ai_tools/comfyui-rocm/start_comfyui_rocm.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

export HIP_VISIBLE_DEVICES=0
export PYTORCH_HIP_ALLOC_CONF="garbage_collection_threshold:0.7,max_split_size_mb:128"
export TORCH_ROCM_AOTRITON_ENABLE_EXPERIMENTAL=1

# Optional: use AMD AMF for FFmpeg encoding
export LIBVA_DRIVER_NAME=radeonsi

conda activate rocm-comfyui-r9700

cd /mnt/c/ai_tools/comfyui-rocm

exec python main.py \
  --listen 0.0.0.0 \
  --port 8189 \
  --use-pytorch-cross-attention \
  --disable-xformers \
  --normalvram
```

### Key Flags Explained

| Flag | Purpose |
|------|---------|
| `--use-pytorch-cross-attention` | Use PyTorch SDPA instead of xformers — safer on ROCm |
| `--disable-xformers` | Prevent xformers from being loaded (CUDA-specific, broken on some ROCm builds) |
| `--normalvram` | Standard VRAM mode (appropriate for 32 GB HBM) |
| `--listen 0.0.0.0` | Accessible from Windows browser at http://localhost:8189 |

### Environment Variables

| Variable | Value | Purpose |
|----------|-------|---------|
| `HIP_VISIBLE_DEVICES` | `0` | Select GPU 0 (use `0,1` for multi-GPU) |
| `PYTORCH_HIP_ALLOC_CONF` | `garbage_collection_threshold:0.7,max_split_size_mb:128` | Prevent VRAM fragmentation (critical for AnimateDiff) |
| `TORCH_ROCM_AOTRITON_ENABLE_EXPERIMENTAL` | `1` | Enable experimental AOTriton kernels for gfx1201 |

Models are shared from `/mnt/c/ai_models/` via symlinks. No model files are copied or duplicated.

### Safety Rules for Symlinks
- Never run `ln -sfn` on a path that contains real files
- Script 05 checks for non-empty dirs before overwriting
- Use `--dry-run` flag to preview symlinks before applying

## Custom Node Installation Strategy

### Tier System
Install in order of risk tier: Green → Yellow (tested) → Orange (with workarounds) → Red (never)

### Constraints Pattern (Critical)
Every `pip install` for custom nodes must include constraints:
```bash
pip install <package> -c /mnt/c/ai_tools/comfyui-rocm/constraints.txt
```

This prevents any custom node's `requirements.txt` from replacing ROCm torch with CUDA torch.

### Phase 5 (Green Tier) Nodes
```bash
cd /mnt/c/ai_tools/comfyui-rocm/custom_nodes

# ComfyUI-Manager
git clone https://github.com/ltdrdata/ComfyUI-Manager
pip install -r ComfyUI-Manager/requirements.txt -c ../constraints.txt

# rgthree-comfy
git clone https://github.com/rgthree/rgthree-comfy
pip install -r rgthree-comfy/requirements.txt -c ../constraints.txt 2>/dev/null || true

# ComfyUI-Custom-Scripts
git clone https://github.com/pythongosssss/ComfyUI-Custom-Scripts
# (no requirements.txt needed)

# ComfyUI_essentials
git clone https://github.com/cubiq/ComfyUI_essentials
pip install -r ComfyUI_essentials/requirements.txt -c ../constraints.txt

# ComfyUI-VideoHelperSuite
git clone https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite
```

## CUDA-Only Warnings

### Avoid These Until Tested

| Package | Risk | Mitigation |
|---------|------|-----------|
| `xformers` (pip) | CUDA-only wheel | Disabled via `--disable-xformers`; build from source if needed |
| `flash-attn` (pip) | CUDA-only wheel | Build from `ROCm/flash-attention` source if required |
| `bitsandbytes` (pip) | Not tested on gfx1201 RDNA4 | Use `ROCm/bitsandbytes` branch if 4-bit quant needed |
| FP8 inference | gfx1201 FP8 compute broken | Use BF16 or GGUF instead |
| `triton` (standalone) | Bundled in PyTorch ROCm | Never install standalone triton separately |

### Flash Attention (if required by ComfyUI-LTXVideo)
```bash
# Build from ROCm source (slower but works)
git clone https://github.com/ROCm/flash-attention
cd flash-attention
pip install -e . -c /mnt/c/ai_tools/comfyui-rocm/constraints.txt
export FLASH_ATTENTION_TRITON_AMD_AUTOTUNE=TRUE
```

## Troubleshooting

### GPU Not Detected After Launch
```bash
# Check device files
ls /dev/dri/
# Should show renderD128 or similar

# Check HIP devices
/opt/rocm/bin/rocm-smi

# Verify env var
echo $HIP_VISIBLE_DEVICES
```

### VRAM Out of Memory
```bash
# Lower memory threshold (more aggressive GC)
export PYTORCH_HIP_ALLOC_CONF="garbage_collection_threshold:0.5,max_split_size_mb:64"

# Or add --lowvram flag
python main.py --listen 0.0.0.0 --port 8189 \
  --use-pytorch-cross-attention --disable-xformers --lowvram
```

### Custom Node Replaced ROCm Torch
```bash
# Check current torch version
conda activate rocm-comfyui-r9700
python -c "import torch; print(torch.__version__)"
# Should show: 2.5.1+rocm6.2 (or 2.9.x+rocm7.2 if upgraded)

# If CUDA version shown, reinstall ROCm torch
pip install torch torchvision torchaudio \
  --index-url https://download.pytorch.org/whl/rocm6.2 \
  --force-reinstall
```

### ComfyUI-LTXVideo Flash Attention Error
```
ImportError: No module named 'flash_attn'
```
Options:
1. Build flash-attn from ROCm source (see above)
2. Comment out flash_attn import in ComfyUI-LTXVideo node and use PyTorch SDPA instead
3. Use GGUF variant of LTX model with ComfyUI-GGUF node (bypasses flash-attn requirement)
